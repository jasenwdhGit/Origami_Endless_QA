# 折纸刷题自习室 - 智能刷题系统

一个功能完整的网页刷题工具，支持 Excel 导入、题型智能识别、多种刷题模式。

## 功能特性

- **Excel 导入**：支持 .xlsx 和 .xls 格式，智能检测 4 种列布局
- **智能题型识别**：自动区分单选、多选、判断题，0 选项自动补齐
- **答案标准化**：自动将「正确/对」→ A、「错误/错」→ B
- **题型筛选**：可按全部/单选/多选/判断过滤题目
- **顺序刷题**：按题目顺序依次作答
- **随机刷题**：随机打乱题目顺序
- **错题复习**：专门复习之前答错的题目
- **进度缓存**：答题进度自动保存，刷新页面可继续上次进度
- **智能作答**：单选题选完自动提交，答对自动跳下一题
- **进度追踪**：实时显示正确/错误数量和正确率，进度条可点击跳转
- **左右切换**：按钮和滑动手势切换上一题/下一题
- **本地存储**：题目、错题、答题记录保存在浏览器本地
- **Bug 反馈**：一键调用邮件客户端反馈问题
- **响应式设计**：支持桌面端和移动端

## Excel 文件格式（支持 4 种布局，自动识别）

### 格式 1 — 用例题库（有表头）
| 答案 | 题目内容 | 选项A | 选项B | 选项C | 选项D |
|------|---------|-------|-------|-------|-------|
| B | 中国的首都是？ | 上海 | 北京 | 广州 | 深圳 |

### 格式 2 — 题目在前
| 题目内容 | 答案 | 选项A | 选项B | 选项C | 选项D |
|---------|------|-------|-------|-------|-------|
| 中国的首都是？ | B | 上海 | 北京 | 广州 | 深圳 |

### 格式 3 — 仅题目+答案
| 题目内容 | 答案 |
|---------|------|
| 中国的首都是？ | B |

> 无选项时自动补齐 A-E 空选项，供作答时手动填写。

### 格式 4 — 答案在前（无表头）
| B | 中国的首都是？ |
|----|------------|

> 系统通过列内容长度自动判断：短列 = 答案，长列 = 题目。

### 说明
- **答案列**支持：`A/B/C/D/E`（单选）、`AB/ACD`（多选）、`正确/错误/对/错`（判断）
- **无选项时**：
  - 答案「正确/对」→ 判断题，自动补齐「正确」「错误」两个选项
  - 答案「错误/错」→ 判断题，同上
  - 答案 A/B/C/D/E → 单选，自动补齐 5 个空选项
- **判断题识别**：选项数 ≤ 2、无选项+判断格式答案
- 支持下载示例文件参考格式

## 快速开始

### 方法一：直接打开

直接用浏览器打开 `index.html` 文件即可使用。

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 方法二：本地服务器（推荐）

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`

## 技术栈

- **HTML5 + CSS3 + JavaScript**（原生实现，无框架）
- **SheetJS (xlsx.js)**：Excel 文件解析
- **LocalStorage**：数据持久化 & 进度缓存

## 使用说明

1. 打开网页后，点击上传区域或拖拽 Excel 文件
2. 等待解析完成后，选择刷题模式（顺序/随机/错题复习）
3. 单选/判断点击即作答，多选需点击「确认答案」
4. 答对自动跳下一题，答错显示正确答案后可手动跳转
5. 顶部导航可切换题目、点击进度条跳转、下拉筛选题型
6. 答错的题目自动记录，可点击「错题复习」重新练习
